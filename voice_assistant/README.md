# Голосовой Помощник с Поддержкой Макросов

Персональный голосовой ассистент, который слушает ваши команды и выполняет различные задачи на компьютере.

## 🎯 Возможности

- **Голосовое управление** - распознавание речи на русском языке
- **Макросы** - выполнение последовательности действий по команде
- **Слово активации** - реагирует на фразу "привет работа"
- **Открытие приложений** - запуск программ по голосовой команде
- **Управление музыкой** - play/pause/stop/next
- **Голосовые ответы** - ассистент говорит с вами
- **Автозапуск** - скрипт для автоматического старта

## 📦 Установка зависимостей

### Для Linux (Debian/Ubuntu):

```bash
# Установка системных зависимостей
sudo apt-get update
sudo apt-get install -y portaudio19-dev python3-pyaudio espeak espeak-data libespeak-dev

# Установка Python пакетов
pip install SpeechRecognition pyttsx3 pyaudio pynput psutil
```

### Для Windows:

```bash
# Установка Python пакетов
pip install SpeechRecognition pyttsx3 pynput psutil
# PyAudio установится автоматически через wheel
```

### Для macOS:

```bash
# Установка зависимостей через Homebrew
brew install portaudio

# Установка Python пакетов
pip install SpeechRecognition pyttsx3 pyaudio pynput psutil
```

## 🚀 Быстрый старт

1. **Запуск ассистента:**
```bash
python assistant.py
```

2. **Произнесите слово активации:**
   - Скажите: **"Привет работа"**
   - Ассистент ответит: **"Доброе утро сэр"**
   - Затем скажите команду, например: **"работа"** или **"время"**

## ⚙️ Настройка макросов

Макросы настраиваются в файле `config.json`, который создается автоматически при первом запуске.

### Структура макроса:

```json
{
  "название_макроса": {
    "response": "ответ ассистента",
    "actions": [
      {"type": "speak", "text": "текст для произнесения"},
      {"type": "open_app", "app": "приложение"},
      {"type": "music", "action": "play"}
    ]
  }
}
```

### Доступные типы действий:

| Тип | Описание | Пример |
|-----|----------|--------|
| `speak` | Произнести текст | `{"type": "speak", "text": "привет"}` |
| `open_app` | Открыть приложение | `{"type": "open_app", "app": "browser"}` |
| `music` | Управление музыкой | `{"type": "music", "action": "play"}` |
| `time` | Сказать время | `{"type": "time"}` |
| `date` | Сказать дату | `{"type": "date"}` |

### Примеры приложений для открытия:

- `notepad` - блокнот
- `calculator` - калькулятор
- `browser` - браузер Chrome
- `firefox` - браузер Firefox
- `terminal` - терминал
- `code` - VS Code
- `spotify` - Spotify

## 🎤 Готовые макросы

По умолчанию доступны следующие макросы:

1. **"работа"** - включает режим работы
   - Отвечает: "включаю режим работы"
   - Запускает рабочие приложения
   - Включает музыку

2. **"отдых"** - включает режим отдыха
   - Отвечает: "включаю режим отдыха"
   - Ставит музыку на паузу

3. **"время"** - говорит текущее время

4. **"дата"** - говорит текущую дату

## 🔊 Голосовые команды для общения

Ассистент понимает простые фразы:

- "как дела" → "у меня всё отлично, спасибо что спросили"
- "кто ты" → "я ваш персональный голосовой помощник"
- "что умеешь" → "я могу открывать приложения, управлять музыкой..."
- "спасибо" → "всегда пожалуйста сэр"
- "пока" → "до свидания сэр"

## ⚡ Автозапуск

### Linux:

1. Сделайте скрипт исполняемым:
```bash
chmod +x start_assistant.sh
```

2. Добавьте в автозагрузку:
   - Через GUI: добавьте `start_assistant.sh` в автозагрузку вашей DE
   - Или создайте systemd сервис

### Windows:

1. Создайте ярлык для `assistant.py`
2. Положите ярлык в папку автозагрузки:
   - Нажмите `Win + R`
   - Введите: `shell:startup`
   - Переместите ярлык туда

### macOS:

1. Откройте "Системные настройки" → "Пользователи" → "Объекты входа"
2. Добавьте `assistant.py` или `start_assistant.sh`

## 🛠️ Расширение функциональности

### Добавление своего макроса:

Отредактируйте `config.json` и добавьте:

```json
"утро": {
  "response": "доброе утро, начинаю день",
  "actions": [
    {"type": "speak", "text": "включаю свет"},
    {"type": "open_app", "app": "browser"},
    {"type": "music", "action": "play"}
  ]
}
```

### Интеграция с музыкальными плеерами:

В файле `assistant.py` найдите метод `control_music()` и раскомментируйте нужные строки:

```python
# Для VLC:
subprocess.run(["vlc", "--intf", "rc", "playlist.m3u"])

# Для Spotify (требуется spicetify-cli или API):
# subprocess.run(["spotify"])
```

## 🐛 Решение проблем

### Микрофон не работает:
- Проверьте права доступа к микрофону
- Убедитесь, что микрофон выбран устройством записи по умолчанию

### Распознавание не работает:
- Проверьте подключение к интернету (Google Speech API требует сеть)
- Попробуйте говорить четче и громче

### Голос не звучит:
- Проверьте настройки громкости системы
- Убедитесь, что установлены пакеты для TTS (espeak для Linux)

## 📝 Требования

- Python 3.8+
- Микрофон
- Подключение к интернету (для распознавания речи)
- Динамики/наушники (для голосовых ответов)
